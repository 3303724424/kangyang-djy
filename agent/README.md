# 灌养·都江堰本地智能服务框架

本项目是“都江堰银龄康养旅居”功能实现骨架。所有推荐、排程与匹配均使用本地 JSON 数据和 Python 标准库算法，**不调用外部大模型、地图、酒店或支付 API**。

## 当前可运行能力

- 根据长者年龄段、行动需求、偏好、预算和出游天数推荐适老景点；
- 自动安排午休与低强度日程，使用本地 Haversine 距离控制明显绕路；
- 匹配适老酒店康养产品；
- 根据服务标签、空闲日期、培训状态和行动协助能力匹配学生陪伴员；
- 生成“需人工确认项”，明确天气、开放状态、库存和身体情况不能由系统自动决定。

## 运行

```bat
cd backend
python run_demo.py
python -m unittest discover -s tests -v
```

运行仅需要 Python 3.10+，不需要安装第三方包。

## 目录

```text
backend/
  app/
    algorithms/       本地推荐、排程、匹配与风险规则
    data/             本地 JSON 数据读取
    domain/           领域数据结构
    services/         用例编排
  data/               都江堰样例景点、酒店、学生陪伴员数据
  tests/              单元测试
  run_demo.py         命令行演示入口
docs/
  功能实现框架.md      开发路线与模块说明
```

## 开发边界

- 样例数据仅用于功能演示，不代表真实景点开放、酒店资质、价格、库存或合作关系。
- 学生陪伴员仅承担讲解、陪伴、协助和信息同步，不提供医疗、护理或紧急救援服务。
- 正式运营前应接入人工审核、授权管理、服务协议、保险与异常工单流程。
